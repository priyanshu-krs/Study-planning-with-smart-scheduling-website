# 📚 Smart Study Planner Pro

A modern and intelligent **Study Planning Web Application** built using **HTML, CSS, and JavaScript** to help students organize tasks, manage study schedules, track progress, and stay productive with smart tools.

## ✨ Features

✅ Smart Task Planner
✅ Study Hours Tracker
✅ Exam Countdown Timer
✅ Pomodoro Focus Timer
✅ Notes Section
✅ Progress Analytics Charts
✅ Streak Tracker 🔥
✅ Dark / Light Mode 🌙
✅ Motivational Quotes 💡
✅ Responsive Modern UI 📱💻
✅ Local Storage Data Saving 💾

## 🛠️ Tech Stack

**HTML5 • CSS3 • JavaScript 

## 🚀 Purpose

Designed to improve productivity, time management, and study consistency through smart scheduling and interactive planning tools.
